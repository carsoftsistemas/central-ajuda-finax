# Central de Ajuda Finax

- `docs/` : artigos em Markdown e imagens
- `ferramentas/anotar.py` + `imagens.json` : gera as imagens marcadas a partir dos prints (pasta `prints/`)
- `overrides/` e `docs/assets/` : visual Carsoft, botão Salvar em PDF

Ver o site no computador: `pip install mkdocs-material` e depois `mkdocs serve`. Gerar: `mkdocs build` (sai na pasta `site/`).
