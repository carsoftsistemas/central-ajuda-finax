# Como alterar um título

1. Localize o título com os botões **Primeiro / Anterior / Próximo / Último**, o botão **Acha** ou o campo **Consulta**.
2. Clique em **Alterar** (++alt+a++). O modo muda para **Editando**.
3. Altere os campos desejados. Para trocar o **valor**, clique sobre ele, pressione ++ctrl+a++ e digite o novo valor. O Valor a Pagar da parcela é atualizado ao gravar. O ícone de calculadora ao lado do campo é uma alternativa.
4. Clique em **Ok** para gravar, ou em **Cancela** para descartar as alterações.

!!! tip "Histórico Complementar 1"
    Aceita um texto curto e aparece no verso do cheque.

!!! warning "Parcela já paga"
    Depois que uma parcela é baixada, os campos de valor ficam bloqueados (cinza). Para alterar o valor, [retire a baixa](baixar-parcela.md#desfazer-a-baixa) antes.
