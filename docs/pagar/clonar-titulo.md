# Como clonar um título

Crie um título novo a partir de um existente, com o mesmo credor, contas, valor e parcelas.

1. Abra o título que quer copiar.
2. Clique em **Clonar**.
3. Na pergunta *"Deseja clonar o registro atual?"*, marque **Baixar título** só se quiser que o clone já nasça pago. Clique em **OK**.
4. O sistema avisa *"Registro clonado com sucesso! Nº (xxxx)..."*. Clique em **OK**.
5. O novo título abre em modo Editando. Ajuste o que precisar (vencimento, valor) e clique em **Ok**.

!!! note
    O clone já foi gravado no passo 4. Se clicar em **Cancela**, ele continua existindo, igual ao original.
