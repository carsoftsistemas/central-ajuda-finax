# Dicas e atalhos

## Pesquisas (lupas)

Em todas as listas de pesquisa (credor, conta, histórico), dê **duplo clique** na linha para escolher o item. Você pode digitar parte do nome em **Valor Campo** e usar "Iniciando com" ou "Que contenha".

## Campos de valor e quantidade

Clique no campo e pressione ++ctrl+a++ **antes** de digitar, para substituir o conteúdo. Sem isso, o número digitado se junta ao que já existe.

## Campos de data

- Clique na setinha ao lado e escolha no calendário. Use as setas do calendário para mudar de mês.
- Ou clique sobre a parte do **dia** e digite os números em sequência, **sem barras** (ex.: 15112026). O cursor passa sozinho para o mês e o ano.

## Teclas de atalho

| Tecla | Onde | Função |
|---|---|---|
| ++alt+i++ | Manutenção | Incluir |
| ++alt+a++ | Manutenção | Alterar |
| ++f4++ | Barra de parcelas | Baixa |
| ++f5++ | Barra de parcelas | Retira baixa |
| ++f9++ | Baixa Múltipla | Aplicar Filtro |
| ++f10++ | Baixa Múltipla | Replicar |
| ++f12++ | Baixa Múltipla | Efetuar baixa |

## Outras dicas

- Depois de gravar uma inclusão, o Finax abre outro registro em branco. Use **Cancela** para sair.
- O botão **Log** mostra o histórico de alterações do título.
- O botão vermelho **Vídeo Aula** abre o vídeo de ajuda da tela.
